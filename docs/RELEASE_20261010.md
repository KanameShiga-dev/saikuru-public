# 2026-10-10 公開更新

20261009・20261010の機能変更を統合。Copilotの計画・レビュー・相談・実装対応、道具と計画の整合性確認、資料プレビュー、スキル選択、コマンド結果の引き継ぎ、レビュー停止処理、担当ごとの利用量記録などを更新しました。

## 保持した保護

- Copilotの標準Shell・書き込み等を無効にし、専用MCPから采来の承認判定を経由します。
- 資料レビュー緩和は既定で無効。OS設定や外部送信の検出時は手動承認を要求します。
- 秘密情報の伏せ字は出力を短く切る前に行います。保護設定の読み込みに失敗した場合は出力を記録しません。
- 管理者のコマンド例外は全文一致。ローカル運用設定・認証情報・履歴・台帳は配布対象外です。

## 未解消の制限

コマンド文字列の検査はOSによる隔離ではありません。呼び出したスクリプトの内部処理までは検査せず、操作自動承認が有効な環境では特に注意が必要です。未登録の顧客名・案件名・個人フォルダ名を完全には伏せられず、ファイル本文すべてに送信前の機密判定が適用されるわけでもありません。これらは今回のpushで解消したとは扱いません。

評価用資材 eval/model_eval/ は、出典未確認の資料と環境固有パスを含むため今回の公開から除外しています。評価機能の説明書は設計資料です。実際の評価用スクリプトは本リリースに含めません。
