# 資料の成果物制作

台帳相談の「資料作成」で必要な成果物形式を選ぶ。PowerPoint（PPTX）、スライドPDF、スライド動画（MP4）に対応。文字資料は従来どおりMD・HTML・TXT・SVG。Word・Excelと音声単独の出力は未対応。

制作は資料専用MCPのgenerate_mediaで行う。AIはタイトル・本文・章別ナレーションを構造化データとして渡す。PowerPointは編集可能な文字、PDFは各ページの画像、MP4は1920×1080のスライド動画として保存。自由な動画編集、実画面収録、既存PDFのそのままの動画変換、字幕同期や画像素材の配置はこの初版の対象外。

音声付き動画はローカルのVOICEVOX（127.0.0.1:50021）を使用する。media_environmentで話者名・スタイルIDを取得し、利用者の選択後に生成。話者の利用規約とクレジットを確認して台本・画面に記載する。本人確認を省略しない。

依頼開始前に選択形式のライブラリ、日本語フォント、動画ならFFmpegを確認。不足時は警告して開始しない。音声指定時はVOICEVOXの応答も確認する。生成後にも失敗し得るため、失敗は完成に置き換えない。

ハーネスは計画担当の起動時にも環境を再確認する。計画担当へ必須成果物形式・利用可能な専用ツール・確認条件を渡し、計画にはbuilderのgenerate_mediaによる指定形式の実制作工程を必須とする。その工程がない計画は自動承認せず停止。計画展開時にも同じ確認を行う。ライブラリがあるだけで完成できるとは断定せず、話者の選択・利用規約・表示視聴確認は別に管理する。

専用保存先内に新しいファイルを作成し、既存成果物は上書きしない。任意のコマンド・URLは受け付けず、固定のPythonレンダラーとFFmpegだけを起動。ソース・設定・DB・認証情報の変更は禁止。外部への公開は別途承認が必要。

PPTX/PDF/MP4の依頼は、依頼ごとの成果物記録・実ファイル・SHA256を確認してから成果確認へ進む。音声指定動画はナレーション生成も必須。実ファイルの存在は品質の保証ではなく、全ページ表示・視聴・発音・利用条件・元のゴールの確認が別途必要。

2026-10-04: 実装と構文確認を実施。実モデルからの制作一巡、実生成・表示・再生、長尺動画、異常時の停止回復は未確認。今回の実装は既存の動画依頼を自動再開しない。
