# 音声による判断通知

- 「音声通知を有効にする」を押すと、新しい判断通知に合わせて「作業の判断事項が発生しました」を読み上げる。
- 声の高さ0.65、速度0.85、音量0.85。端末に日本語男性音声があれば優先し、日本語の端末内音声、その他の日本語音声の順に使用する。声質と高さの反映は音声エンジンに依存する。
- 「声を試聴」で同じ文を再生できる。有効化時にも文を再生し、ブラウザでの音声再生を開始する。
- まとめて通知が発生しても読み上げは1回。同じ判断を更新ごとに繰り返さず、読み上げ中に通知音声を積み重ねない。
- 再度ボタンを押すと停止し、選択はブラウザに保存する。音声非対応や再生エラー時は画面内通知を使う。
- マイクは使用しない。読み上げるのは固定の通知文だけ。ダッシュボードを開いている間の機能。
