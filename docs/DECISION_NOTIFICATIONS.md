# 判断待ちの通知

- ダッシュボードが開いている間、状態更新で新しい判断・確認待ちや作業停止を検知し、画面内に通知する。
- 「内容を確認」で対象のタスクを開く。別の入力ダイアログを開いているときは入力を保持し、先に閉じる案内を出す。
- 同じ判断の識別子をブラウザのローカル保存に最大300件保持し、再読込でも通知を繰り返さない。内容や回答を通知の記録に保存しない。
- 回答済み・中止済み・終了済みの通知は状態更新時に消える。「通知を閉じる」は回答ではなく、判断待ち自体は続く。
- 「PC通知を有効にする」を押すとブラウザの通知許可を求める。許可後の新しい判断をPCにも通知する。PC通知には作業内容を表示しない。
- 通知APIに対応しないブラウザ、スマホ、許可されない場合も画面内の通知を使用する。
- ページを閉じた状態での通知、サーバーからのWeb Push、スマホでのOS通知は今回の実装には含まれない。
