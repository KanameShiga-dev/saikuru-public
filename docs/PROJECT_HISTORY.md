# プロジェクト履歴

作業ボードまたは台帳の「プロジェクト履歴」から `/history` を開きます。
プロジェクト、依頼の入口、依頼名で絞り込み、依頼を選ぶと承認記録と作業イベントを確認できます。
資料作成の依頼は保存先と読み取り元の両方から検索できます。

- 台帳の相談記録に紐づく依頼は「台帳からの依頼」。本機能追加後の直接作成は「新規依頼」。入口が保存されていない過去の依頼は「入口未記録」。
- 横棒は担当工程の記録時刻を使用。待機、実行中、停止、確認待ちを区別します。個々の再試行の区間は現在の工程レコードだけでは復元できないため、詳細イベントも参照します。
- イベントは新しい順に200件ずつ追加表示。保持されている記録が対象で、削除済みの履歴や未記録の操作は復元しません。
- 依頼者・監視担当・確認者・承認者の本人確認は未実装。人の名前を推測せず未記録と表示します。AI担当と人の担当は別です。
- 読み取り専用画面です。AIの追加呼び出しやWebへの送信はありません。既存のローカル画面認証を使用し、承認操作は作業ボードで行います。
- ページの更新ボタンで最新の状態を取得します。リアルタイム自動更新はありません。
- チーム利用のログイン・人物役割・閲覧権限・個人ライセンスでの分散実行は今後の課題です。
