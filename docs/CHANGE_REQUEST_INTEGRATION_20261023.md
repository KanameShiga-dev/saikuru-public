# 2026-10-23版パッチの統合記録

実施日：2026-10-25。基準：統合版 `b404bdf`、提供パッチの基準 `6101fc1`。

## 統合した変更

1. Claude / Copilotの自動切り替えを設定で選択し、現在の利用枠が実測で尽きている場合の着手前切り替えに対応。
2. Copilotのquotaエラーをエンジンと利用量表示へ伝え、手動選択したモデルが一度も動かず戻る問題を修正。
3. 担当の詳細をタブで分類。既存の承認、入力、フォーカス復帰、技術詳細の表示制御を保持。
4. 終了済み依頼は表示期間外でも直近10件を表示。履歴一覧はSQLの件数集計を使い、個別詳細は従来どおり取得。
5. 台帳の指示ファイル確認を折りたたみ、警告時は開いて表示。
6. 背景実行登録の資格情報入力をCredUIへ変更。資格情報の入力・タスク登録自体は実行していない。
7. 修正工程で実行記録が欠ける場合の1回の確認依頼と、修正不能の引き継ぎ後の利用者判断に対応。

## 現行版と合わせた箇所

- 同梱ファイルを丸ごと上書きせず、共通ベースから3者比較。競合した5ファイル（engine、app、index、ledger CSS、style CSS）の既存処理を保持。
- P0契約の依頼は引き続き自動フェイルオーバーしない。P0の成果物・目標・正式受領とG2/G3の承認経路を保持。
- 利用量による事前判定は予測に使わず、現在のモデルに適用される最新の枠だけを対象とする。別モデル専用枠・期限を過ぎた枠・古い値は切り替え理由にしない。
- Copilotの月間上限が未設定でも、実際のquota拒否があれば枠切れを表示する。結果イベントを残さずCLIが終了する場合にも、その直前のエラーを保持。
- 詳細タブにARIAの対応付けを追加し、標準画面で非表示の技術欄だけのタブを隠す。非表示の失敗欄で標準画面のタブを赤くしない。
- CredUIのドメイン情報を含めてアカウントを比較。Windows PowerShell向けにスクリプトをUTF-8 BOM付きで保存。
- 更新対象の既存テストの架空データを、現行の報告形式とG2/G3の承認手順に合わせた。製品側の承認や報告検査は緩和していない。

## 適用と復旧の境界

- 実行対象はソースコードの取り込み。DB、設定、認証情報、既存依頼、既存作業フォルダ、タスクスケジューラには変更を加えない。
- 本体の既存ソースを控えてから対象ファイルだけを更新し、書き込み前後のハッシュを記録する。既存の本体固有差分は維持する。
- サービスの起動、実Providerの呼び出し、背景実行登録、公開・pushはこの作業に含めない。
- 復旧は、統合版は変更差分の取り消し、本体は控えた対象ソースの復元。DBの巻き戻しは不要。
