# Existing-information harness supplementation

New conversion previews supplement generated drafts from local README/package.json/
index.html/sw.js evidence. Existing harnesses use the ledger's “既存情報からハーネスを補完”
button: inspect before/after, confirm, apply. Nothing is applied by the read-only preview.
Six documentation targets are supported: GOAL, ARCHITECTURE, COMMAND_ALLOWLIST,
SECURITY, .harness/context, .harness/definition-of-done. Scope/permissions are not
automatically approved. Purpose placeholders can be replaced with attributed README
statements; other facts use a managed evidence section. Keep UNKNOWN for unestablished
intent/users/acceptance conditions; documentary statements are not runtime proof.

No model/API, install or project command is executed. Commands are unapproved candidates.
Source hints identify camera/storage/communication APIs, not full data-flow analysis.
Source collection is bounded to depth 2, 100 allowlisted files, 256KB each; data/private/
generated/model/link paths are excluded. Secret-pattern matches are withheld. This is
not a comprehensive secret scanner; never use private records as README content.

Each fact has source file/line and a documentary/existence/code-hint label. Preview shows
full affected harness documents after secret checks. Existing custom text is retained
outside the generated evidence block; previous generated evidence is replaced on repeat.
Review manual edits inside that block before approving replacement.

Apply requires authenticated UI/CSRF marker, confirmation, matching project/ledger,
source and target hashes, and no reparse paths. Preview expires after 30 minutes. Only
these documentation files are updated, not application source or permissions. Originals
and a receipt are stored under Agent Team data/harness-fill-backup-*/. The app's existing
backup/retention policy must preserve these before pruning. Restore only after comparing
against later edits. Existing conversion remains no-overwrite; use supplementation for
existing files. No project is bulk-updated by installing this feature.

Current checks: Python and JavaScript syntax. Browser flow, functional apply/rollback,
and comprehensive regression tests not run for this implementation request.
