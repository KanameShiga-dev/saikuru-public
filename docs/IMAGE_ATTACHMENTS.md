# 画像を使った作業依頼・台帳相談

2026-10-04 ローカル実装。初期実装時点では未公開。現在の公開仕様は先頭の更新案内を参照。

## 操作
新規依頼と台帳相談にPNG/JPEGの選択・貼り付け、プレビュー、送信前の取消を追加。依頼／相談1件につき4枚、各5MB、合計15MB。各辺8192px、1600万画素以内。相談では送信済み画像を次のモデル呼び出しと作業ボードへの依頼に引き継ぐ。新しい画像は通常の相談送信で追加し、再試行は前の画像を再利用する。画像のみの相談も可能。新規依頼は従来どおり依頼名・目的を入力する。

## 保存と境界
- `team.sqlite3`のattachmentオブジェクトにUUID・名前・MIME・サイズ・寸法・SHA256を保存。job/session/messageに画像IDを保存。画像本文は`data/attachments/<UUID>.bin`へ保存する。既存DBへの破壊的移行はない。
- POST `/api/attachments`は既存画面認証と`X-Agent-Team-UI`が必要。GET `/api/attachments/image?id=`も認証が必要。名前を保存パスに使わず、任意パス・URL・SVGは受け付けない。ヘッダーで形式・寸法を検査し、読み出し時にハッシュを検証する。画像の完全なデコード検証はしない。
- 添付の選択だけでは保存・送信しない。依頼／相談送信時にアップロードする。アップロード後の依頼送信失敗では画像が未関連のまま残る場合がある。再送は成功済みのIDを再利用する。
- 保存画像全体は512MBまで。自動削除・削除画面は追加していない。保存は履歴として継続し、DBのみのバックアップでは画像本文を復元できないため`data/attachments`も一緒に保全する。
- 画像をプロジェクトのフォルダにコピーしない。画像内の文章は未信頼の参考資料として扱い、承認・作業範囲・権限を変えない。メタデータを自動除去しないため、利用者が送信前に個人情報・認証情報を除く。
- 認証済みローカル利用者と既存スマホ入口は同じ権限で画像を参照する。個人ごとの閲覧権限は既存機能と同様に未実装。

## AIへの受け渡し
Codexは導入済みCLIの`app-server generate-json-schema`で確認した画像入力（type=image、url=data URI）。Claudeは画像がある場合だけ`--input-format stream-json`に切り替え、text/imageの配列をuser messageとして送る。従来の画像なし入力は維持。計画・実装・レビューのContextは依頼の同じ画像IDを読み出す。画像未対応のモデルや不正画像は接続エラーとして扱い、見たと推測しない。

参照：[Claudeのストリーミング画像入力](https://code.claude.com/docs/en/agent-sdk/streaming-vs-single-mode)、[CLI入力形式](https://code.claude.com/docs/en/cli-reference)。
