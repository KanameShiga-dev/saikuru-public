# 資料作成の保存先を計画から決める（2026-10-05）

利用者の指示により、台帳相談からの「資料作成のみ」の依頼で、保存先の入力欄と確認チェックを廃止した。

- 保存先は計画プロンプトに書かれたパスから決める（`Consultations._output_from_plan`）。「保存先・出力先・成果物」などを含む行を優先し、ファイルパスなら親フォルダを使う。
- 対象は C:\Projects 以下のみ。C:\Projects 直下そのもの、采来の内部フォルダ、読み取り元を含む上位フォルダは採用しない。存在しないフォルダは作成する。
- 該当するパスが無ければ、元プロジェクトのフォルダに保存する。
- 保存先は読み取り元と同じフォルダ・その下でもよい（従来は別フォルダ必須で、計画どおりの場所だと弾かれていた）。資料ツールは md/html/txt/svg/pptx/pdf/mp4 の新規作成のみで、既存ファイルは上書きしない（自分で作った資料の更新はSHA256一致時のみ）。読み取り元の上位フォルダは書き込み範囲が広がるため従来どおり拒否（`document_tools.py`）。
