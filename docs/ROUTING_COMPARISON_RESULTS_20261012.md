# 采来の実行経路比較：隔離評価結果（2026-10-12）

状態：隔離試作・小規模比較を実施。通常サービスの経路・設定は変更していない。公開・pushなし。

## 条件と判定の範囲

架空の単一Pythonファイル `calculator.py` にある合計関数の不具合修正。通常経路 F、計画AIだけを省いた軽い経路 L、直接Claude CLI Dを比較した。F/Lは各3回の有効な対比較（順序 F→L、L→F、F→L）。Dは確定版の課題で1回。毎回新品のプロジェクト・専用DBから開始した。通常サービスのDB・案件は使用していない。

F/Lは全工程で要求モデル `sonnet`／medium、CLIの起動報告は `claude-sonnet-5-5`。Dも同じ実モデルの起動報告を取得した。effortの実効値はCLIの起動報告で独立確認できておらず、指定したmediumとして記録する。経験・Skillは追加せず、文脈予算・画像化はoff、セキュリティレビューは全件、修正上限1、道具・許可範囲は固定した。Dはレビュー・采来の承認・履歴を持たないため、F/Lとの差を計画工程だけの効果とは呼ばない。

独立採点は空配列、1件、正負混合、負数のみ、入力不変を検証した。F/Lでは制作後かつレビュー前に合格証拠を記録し、受領時に同じ採点を再実行した。受領操作は評価ランナーによる**架空課題の代理操作**であり、利用者本人の操作時間や実利用の受領を測っていない。

有効な3組に限れば、合格・通常受領1件あたりFは163,091、Lは約109,543トークン。工程別合計はFが計画100,986・制作146,038・レビュー242,249、Lが制作126,389・レビュー202,239。軽い経路では計画工程がなくなったほか、後続工程の消費も下がった。後者の原因は特定していない。所要時間はFが42.3〜48.4秒、Lが33.3〜36.2秒。これはAI処理を含む評価ランナー時間で、人の作業時間ではない。

Dは独立採点合格、23,683トークン、7.7秒、追加ファイルなし。F/Lの平均より少ないが、通常・セキュリティレビュー、未確認事項の記録、操作承認、停止復旧を実施していない。Dは単発であり、直接CLIに一般的な削減率を付けない。

## 除外した予備試行と総消費

- 当初の `gpt-6-sol` 条件は計画成功後、Codex Windowsサンドボックスの起動確認で制作前に失敗。取得済み99,053トークン。制作担当のusageはunknownで0と補完しない。安全設定を緩めず、以後は全工程を同じClaude Sonnetに変更した。
- 証拠をレビュー後にしか見せない組、証拠に再計算できないSHA-256を求めた組、将来の再採点を必須事項として書いた組は、各F/Lが独立採点に合格してもすべて `accepted_with_pending_checks` になった。合格1件あたりの主指標から除外し、消費は捨てていない。未確認事項の記録が実際の証拠提示順序に敏感であることを示した。
- 有効な3組、予備試行、Codex失敗、Dの2回を合わせ、**取得済み総量は1,756,537トークン**。利用者指定の200万トークン以内。予備試行の費用を有効3組の削減率に混ぜていない。UNKNOWNの実消費があれば総量の外にあるため、上記は測定値の合計であり厳密な請求上限の証明ではない。

## 機能別の価値判断

| 機能 | この評価で確認したこと | 判断 |
| --- | --- | --- |
| 計画AIを省く | LはFより3組とも少ないトークンで同じコード修正・2種のレビュー・通常受領に到達 | 明確な単一制作課題の隔離試作では有望。ただし課題1種類・同じモデルに限る |
| 通常・セキュリティレビュー | F/Lは両レビューを実施し、両経路で指摘と未確認事項を受領画面へ届けた | 記録と確認の機能は動作。レビューによる実不具合の発見効果はこの簡単な課題では測れない |
| 直接CLIとの使い分け | Dも独立採点合格し、トークンと時間が最小 | レビュー・承認・復旧を必要としない明確な小課題ではDが実用上有利。安全と人の確認は別途担う必要がある |
| 受領ゲート | 予備試行では証拠が後からそろっても条件付き受領が残った | 未確認事項の解消証拠を受領へ反映する流れに改善余地。証拠の提示順序に依存する |

この結果だけで軽い経路を通常サービスへ出さない。直接CLIを優先する条件、軽い経路の対象と既定OFF、証拠が後からそろった場合の受領更新、レビュー費用と人の操作を含む追加評価は[本番改修方針](ROUTING_PRODUCTION_DECISION_20261012.md)に定めた。別の課題種類・実利用者の受領・長期運用は未検証。
