# 確認指摘からの修正と再確認

調査・確認担当（researcher）が `needs_changes` を返すと、元の依頼の許可範囲で修正担当を作り、同じ確認担当による再確認を挟みます。後続工程の依存先は再確認へ変更します。確認担当自身は読み取り専用のままです。

既存の自動修正上限に達した場合は停止します。カードを開き、指摘の根拠・修正箇所を確認してください。未完了項目を残して進める場合は「引き継ぎ終了」で範囲を指定します。合格済みとして扱う機能ではありません。

前回と空白以外が同じ指摘はイベントに記録します。言い換えの同一性までは判定しません。`needs_changes` の再試行には補足を必須にし、修正した箇所と根拠を求めます。補足が正しいことの自動保証はありません。

計画・確認担当への指示に、必須条件は利用者の依頼・回答・安全制約を根拠とし、AIが追加した分量や行数は目安として扱う規則を追加しました。この規則はモデルへの指示であり、条件の意味をコードで完全に判定するものではありません。
