# 添付変更依頼 第2弾の統合

対象はsaikuru-change-request-20261006.zip（公開版f7e1263基準）。現行本体へ差分を統合し、企業記憶・スキル管理・Claude利用枠15分間隔を保持しました。環境固有のREADME全文は置き換えません。

## 取り込んだ8項目

1. 調査・実装担当のWeb検索と検索語の送信前検査。
2. 通常レビュー後のセキュリティレビューを全依頼に追加。security_review=alwaysが既定、planner指定時は計画判断に従う。
3. 成果の理由付き拒否から修正・通常レビュー・セキュリティレビューを再開。理由なしは停止。停止したカードにも差し戻し入力を追加。
4. 制作入力エラーのページ番号・原因を担当へ返す。
5. PPTXの表紙・章扉・配色・本物の表・図・発表者メモ。PDF/MP4の表・図は文字表現。
6. 資料の出力ルートと相対パス指定を説明。
7. 保存先の見出し直下3行を判定し、参照元・入力元の行を除外。
8. MSIX内のPython依存導入に関する注意。ライブラリの自動導入なし。

## 統合時の補強

- 台帳相談も検索語の検査を通し、WebFetchは許可しない。未検査の検索追加引数を拒否。
- Codex組み込み検索には検索前フックがないため無効化。統括MCPのweb_searchから同じ検査後にBingのRSS検索を行う。固定HTTPS送信先、リダイレクト拒否、20秒・20万bytes・8結果まで。本文は取得しない。失敗は未調査として返す。
- 検索語の文字正規化、制御文字、ポリシー形式も検査。data/websearch-policy.jsonの企業固有語・ドメインは運用登録が必要。未登録語・言い換えの検出は保証しない。分類モデル・匿名化・全通信の企業プロキシ制御は未実装。
- 許可した検索語もログへ残さず、理由・文字数のみ記録。Bash原文も残さず操作分類・文字数・SHA256を記録。レビューへ過去の操作原文を転記しない。
- 変更ファイル検査は500ファイル・探索1万件・指摘60件まで。範囲外リンク、認証ファイル・鍵を読み取らず、指摘の値は伏せる。限定された規則検査は漏洩がない証明ではない。
- 差し戻しは元の許可範囲を維持。進行中の工程・未回答質問・矛盾があれば拒否し、古い成果承認は失効させる。
- 表紙・章扉の表・図・画像は黙って省かずcontentへの変更を要求。縦図の高さも節点数に応じて判定。

## 確認と制限

Python11ファイルとJavaScriptの構文を確認。添付元の検証報告は本環境の実施結果ではありません。実モデルの検索、差し戻しの一巡、PowerPoint表示、RSSの実応答、全セキュリティレビューの一巡は未確認です。テストは追加・実行していません。

セキュリティレビュー分のCLI呼び出しと利用枠消費が増えます。既存サンドボックス・承認は維持します。Shell等の通信は検索ガードで全面制御するものではありません。公開・pushは別の操作です。
