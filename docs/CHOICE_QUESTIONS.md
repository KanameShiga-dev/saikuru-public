# 判断質問の一括回答

## Completed
- 質問は最大6件、選択肢は各1〜6件。AIへの指示では通常2〜4択を要求。
- 各質問で1つのボタンを選択。補足・必須入力は選択肢の隣に表示。狭い画面では折り返す。
- 「まとめて回答して続行」で質問ごとの選択IDと補足を保存し担当へ返す。未回答・必須空欄・無効選択肢・重複送信・期限切れをサーバーでも拒否。
- 「あとで回答」は回答を送らず画面を閉じる。下書きは同じページ内で保持、再読み込みすると失われる。
- Codexの対話中の質問は質問IDごとに回答。完了結果でblockedとなった担当は回答を追記して再開し、後続担当を先に進めない。
- 新しい計画でも質問可能。既存の自由文の質問には架空の選択肢を付けず、入力式の回答ボタンを表示。

## Human-centered considerations
- 自動選択せず利用者が明示して回答。入力時は対応する選択肢が選択される。
- エラーは質問の近くに表示し下書きを保持。履歴には質問・選択・補足をまとめて記録。
- 通常の操作承認・計画承認・成果受入は既存の承認/拒否を継続。

## Security and privacy
- 質問への回答はファイル操作の包括承認には使用しない。個々の操作の権限確認を継続。
- 秘密情報の質問をモデルへ禁止し、CodexのisSecret付き質問は拒否。補足はDBに記録されるため秘密情報を入力しない。
- 既存blocked質問の移行は内容を変えず表示可能にするだけで、自動回答・自動再試行はしない。

## Residual risks and unverified items
- 再開は担当の新しい実行。モデルに既存変更確認と重複実行防止を指示するが、外部操作の厳密な一回実行を保証するものではない。
- 作業中に新仕様へ切り替えず、今回の反映時には実行中タスクなしを確認した。
