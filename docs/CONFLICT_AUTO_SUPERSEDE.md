# 時間差の情報矛盾を自動で更新扱いにする（2026-10-05）

利用者の指示により、引き継ぎDB（`team_handoff.py` の `HandoffDB.fact`）の矛盾判定を変更した。

## 変更内容

- 同じ依頼の中で、AIの報告（model_reported）どうしが同じ項目で食い違った場合は、後の報告を現在の情報として採用し、前の報告は superseded として履歴に残す。依頼は止めない。
- 監査用に conflicts へ `status='resolved'`、`resolution={"choice":"new","auto":"later_model_report"}` の行を残す。
- 利用者が確認・決定した情報（user_confirmed / user_decision。前の依頼の判断を含む）とAI報告が食い違う場合は、従来どおり「情報の矛盾の確認」で止める。
- 同じ値の再報告は従来どおり duplicate。

背景：計画時「MANUAL.mdはまだ無い」→作成後「作成済み」、レビュー1回目「未反映」→再レビュー「反映済み」、計画時「Python UNKNOWN」→実行時「3.13.5」のような時間差の報告で依頼が止まっていた。

## 限界

AIどうしの本当の食い違い（同時点で異なる主張）も後勝ちになる。前の報告は履歴に残るため、必要なら引き継ぎDBの履歴から確認する。
