# 選択肢がない判断のヘルプ

- 「あなたの判断」で選択式の質問がないカードに「回答方法のヘルプ」ボタンを表示する。
- 詳細の先頭にヘルプを設け、入力や承認が必要な場合はその場所へ移動できる。
- 回答を渡す欄は「回答・補足の入力欄」、送信操作は「回答・補足を送って再試行」と明記する。
- DBの事実登録は質問への回答や再開操作ではないと説明する。
- 「未完了項目の引き継ぎには利用者の範囲指定が必要」の既知の判定エラーは、回答不足ではなく統括側の修正が必要と説明する。
- ヘルプ閲覧ではタスクを再開しない。既存の入力と操作確認を維持する。
