# 指示ファイルの容量警告

調査日：2026-10-04。対象は采来のプロジェクト指示ファイル。AIモデルのコンテキスト全体の上限とは区別する。

## 公式の根拠

|担当|仕様・推奨|警告|
|---|---|---|
|Codex|`project_doc_max_bytes`の既定は32 KiB（32768 bytes）。AGENTS.override.md、AGENTS.md、設定した代替名の順で、各階層から最大1ファイルを選ぶ|指示候補の合計80%以上で注意。上限到達・単独超過で末尾・後続の省略リスク|
|Claude Code|CLAUDE.mdは200行未満を推奨。長い指示はコンテキストを消費し、指示への追従が低下する。現在の公式資料では4 MiB以下を全文読み込み、超過はスキップ|200行以上は推奨超過の注意。4 MiB超は読み込み対象外の警告|

- [OpenAI：AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
- [OpenAI：設定リファレンス](https://learn.chatgpt.com/docs/config-file/config-reference)
- [Anthropic：Memory](https://code.claude.com/docs/en/memory)

Claude CodeのMEMORY.mdの200行または25 KBという読み込み制限はCLAUDE.mdの制限ではない。AGENTS.mdの直接読み込みはClaude Codeの版・設定に依存する（公式資料ではv2.1.277以降）。CLAUDE.mdで文章だけの「AGENTS.mdを読む」を書いても、自動読み込みの保証にならない。`@AGENTS.md`は自動インポートの方法だが、インポートは整理でありコンテキスト削減ではない。

長い1行で200行の注意を回避してしまうケースにも対応し、采来の独自の注意目安としてCLAUDE.md等は32 KiB以上でも警告する。この値はClaude Codeの公式上限ではない。

単に「40 KB以下なら適切」と判断しない。日本語の文字数とUTF-8のバイト数も異なる。

## 操作・対象

- 台帳の再調査・登録：開始フォルダまでの候補を記録し、一覧に調査時点の警告数を表示する。
- 台帳の詳細を開く：現在の容量を読み取り専用で再確認。子フォルダも限定して調べる。ファイル別のKiB・bytes・行数と確認日時を表示。「容量を再確認」で更新する。
- 新規依頼：対象プロジェクト選択時に警告する。確認中・失敗・未確認を表示する。
- ハーネス調査：既存の指示ファイルの容量警告を調査結果に表示する。
- 新規依頼・台帳相談からの依頼作成：診断を依頼に保存し、その依頼の作業カードに作成時点の警告を表示する。導入前の依頼に記録を捏造しない。

`team_instruction_health.py`を共通処理とし、指示本文を返却・保存・AIへ送信しない。本文は行数計測のためローカルで読むだけ。警告は承認、作業中止、自動短縮、自動分割、読み込み上限や権限変更にはならない。常時監視・OS通知ではなく、上記操作時の診断。

## 確認範囲と限界

Codexの利用者設定と開始フォルダの.codex/config.tomlから必要な上限・代替名だけを参照する。プロジェクト設定の信頼状態が未確認なので、プロジェクトの上限引き上げで警告を消さず、利用者/既定との小さい値を使う。利用者共通のAGENTSとプロジェクトの階層を合わせた保守的な候補を表示する。実効値・実際の読み込み結果を断定しない。

親Gitから開始フォルダまでと、その下の指示を調べる。Gitルートを検出できない場合は開始フォルダだけ。独自project_root_markers、親フォルダの設定、プロファイル・CLI/API上書き、管理者設定、非標準ホームは完全には再現しない。Claudeの利用者CLAUDE.mdは通常ホームまたはCLAUDE_CONFIG_DIRを参照するが、采来専用CLIの実効ホームは未確認。Claudeの@import・.claude/rules・管理者の規則を展開しない。小さなルーターでも参照先や他の指示が大きい場合がある。

深さ6、400フォルダ、128ファイル、各フォルダ2000候補、行数の読み取り合計16 MiB、探索4秒で打ち切る。1ファイル4 MiB超は容量だけを測る。リンク・junction・依存・Git管理・データ・バックアップ・秘密情報候補の領域等を辿らず、家庭関連は検査しない。未確認範囲を警告する。UTF-8以外は容量のみ確認。内容・ファイルの実行、外部参照の取得、設定ファイル全体の表示は行わない。

「警告なし」は全指示を読み込んだ保証ではない。変更後は再確認し、各CLIの/contextや読み込み元の案内を確認する。実際のAIへの追従も別途確認が必要。

## 対処

必須ルールと権限・承認境界を先頭の短いルーターに残す。詳細は必要時に参照する文書・Skill、Claudeのpath-scoped rulesへ移す。Codexは作業ディレクトリまでの累積なので、同じ指示チェーンに分けるだけでは上限を避けられない。変更は開発依頼として範囲を指定し、勝手に対象プロジェクトのファイルを書き換えない。
