# デモ用 新規依頼サンプル（スキル作成まで）

采来の一連の流れ（新規依頼 → 台帳登録・ハーネス化 → 計画 → 実装 → レビュー → セキュリティレビュー → 受け入れ）に加え、**作業で得た経験からスキルを作る**ところまでを見せるためのサンプルです。

## 0. 準備（画面で入力）

1. 作業ボードの「＋ 依頼を追加」を開く。
2. 対象プロジェクトの「＋ 新規フォルダを作成」で、親フォルダ `C:\Projects\samples`、名前 `06-csv-export` を作成して選択する。

## 1. 依頼の入力

**依頼名**

```
06 開発：Excelで文字化けしない顧客一覧CSVの出力
```

**達成したいこと・完了の条件**

```
Python標準ライブラリだけで、架空の顧客一覧をCSVに出力する export_customers.py を作る。
- 列：顧客ID、氏名（明らかに架空）、都道府県、登録日、メモ（カンマ・改行・ダブルクォートを含む行を必ず混ぜる）
- 10件、乱数シード固定。Excelでダブルクリックして開いても日本語が文字化けしないこと。
- 出力したCSVを読み戻して、件数・列数・特殊文字を含むセルが壊れていないことを確認する test_export.py（unittest）を作り、実行結果を報告する。

【経験の記録（スキル化のため必須）】
作業で得た再利用できる教訓を、context_updates に次のキーで1件記録すること。
- key: experience:lesson:日本語CSV出力:Excelで開くCSVをPythonで作るとき
- value: 文字コード・改行・クォートの具体的な設定と、そうしないと何が起きるかを2〜4文で
- evidence: 根拠にしたファイル名・行と、確認したテスト結果

共通条件：変更・作成してよいのはこのフォルダ内のファイルのみ。外部パッケージの導入、ネットワーク送信は行わない。実在の個人情報は使わない。
```

**チェック**

- 「計画後、依頼内の作業とレビューを自動で進める」：オン
- 「依頼内容…をAIに送信し、CLIの利用枠を使うことを確認しました」：オン

→「計画を開始する」

## 2. 自動で進むところ（見せどころ）

| 段階 | 画面での見え方 |
|---|---|
| 受付 | 通知に「台帳に登録しました。ハーネスのコンバートで19件を作成しました」 |
| 計画 → 実装 | 作業ボードのカードが「チームが作業中」に移る。コマンドは自動承認（操作の自動承認が有効） |
| レビュー → セキュリティレビュー | 通常レビューのあと、毎回セキュリティレビュー（操作記録と変更ファイルの機械チェック付き） |
| 受け入れ待ち | 「あなたの判断」に成果の確認が出る |

受け入れで「拒否」し理由を書くと、その指摘で修正担当とレビューが自動で再開する（差し戻しのデモにも使える）。

## 3. スキル候補を作る（人の確認）

AIの記録だけでは「未確認」のため、スキル候補になりません。人が確認して登録します。

1. 依頼のカードを開き「引き継ぎDBの履歴」で、AIが記録した `experience:lesson:日本語CSV出力:Excelで開くCSVをPythonで作るとき` の内容を確認する。
2. 同じカードの「引き継ぎ情報を登録・訂正する」を開き、次を入力して「DBに保存」：
   - 項目：`experience:lesson:日本語CSV出力:Excelで開くCSVをPythonで作るとき`
   - 現在の正しい内容：AIの記録を確認した文（必要なら直す）。例：
     ```
     Excelで開くCSVは encoding='utf-8-sig'（BOM付きUTF-8）で書き、open(..., newline='') と csv.writer の既定（QUOTE_MINIMAL）を使う。BOMが無いとExcelがShift_JISとして読み日本語が文字化けし、newline='' が無いとWindowsで空行が挟まる。カンマ・改行・ダブルクォートを含むセルはcsvモジュールに任せれば正しくクォートされる。
     ```
   - 根拠：`export_customers.py と test_export.py の結果を確認（デモ）`
3. カードを開き直し、「引き継ぎDBの履歴」→「経験から作成したスキル候補（未有効化）」に候補が出ることを見せる。「SKILL.md候補を保存」でダウンロードもできる。

## 4. 正式化と一覧

1. 候補を開き、用途・適用条件・手順・必要な道具と権限・検証方法と結果・失敗時の対応を入力する。例：
   - 用途：Excelで開く日本語CSVをPythonで出力する
   - 適用条件：Excelで開くCSVをPythonで作るとき
   - 手順：① open(path, 'w', encoding='utf-8-sig', newline='') で開く ② csv.writer で書く ③ 読み戻して件数・特殊文字セルを確認する
   - 道具と権限：Python標準ライブラリ（csv）。対象フォルダ内の書き込みのみ
   - 検証方法と結果：unittestで件数・列数・特殊文字セルを確認（デモの実行結果を記入）
   - 失敗時の対応：文字化け→BOMの有無を確認、空行→newline='' を確認
2. 確認チェックを入れて「確認した版を登録して有効化」。
3. 画面上部の「スキル一覧」（`/skills`）で有効版を見せる。正式版のSKILL.mdのダウンロード、別プロジェクトへの適用もここから。

## 注意

- このデモの一連（経験の記録 → 候補 → 正式化 → 自動参照）は、上流でも本環境でも実モデルでの一巡確認がまだです。経験がキーどおりに記録されない場合は、手順3で人が直接登録すれば候補は作られます。
- 1回のデモは、実行に数分〜十数分、Claudeの利用枠を使います（計画・レビューは opus）。
